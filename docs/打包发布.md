# 打包发布

目标是一个 `NiceReadingLens-Setup-0.1.0.exe`：双击装好，开始菜单出现快捷方式，点开就用。

## 生成安装包

```powershell
cd E:\liruiqin\reading-helper
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

四步走：装打包依赖（PyInstaller + cryptography）、现画一张图标、PyInstaller 出 exe 目录、Inno Setup 压成安装包。

产物有两个：

```
dist\NiceReadingLens\                               绿色目录，双击里面的 NiceReadingLens.exe 就能跑
dist\installer\NiceReadingLens-Setup-0.1.0.exe      安装包
```

只要绿色版就不加最后一步：

```powershell
powershell -ExecutionPolicy Bypass -File packaging\build.ps1 -SkipInstaller
```

## 前置条件

Inno Setup 6 是可选的，只装绿色版就不需要。想压安装包就 `winget install JRSoftware.InnoSetup`，装完重跑脚本会自动找到。

首次打包要联网装 PyInstaller 和 cryptography，之后加 `-SkipDeps` 跳过。打包用的还是项目自带的 `.venv`，跟开发环境共用一套依赖。

## 装完是什么样

装到 `C:\Program Files\NiceReadingLens`，需要管理员权限。开始菜单和（可选）桌面会有快捷方式。

安装时默认勾选「添加防火墙规则」，给 exe 放行一次专用网络的入站，不然手机连不上；卸载时这条规则一起删掉。

启动后弹一个控制台窗口，里面是电脑端地址、手机端地址、二维码和 Ollama 状态，同时自动打开浏览器到阅读页。这个窗口关掉服务就停了——这是有意为之，否则用户不知道程序还在后台跑。

安装向导最后一页会检查 Ollama，没装的话提示去哪装、执行哪条命令。识别和排版不受影响，只是暂时没有中文。

## 数据放在哪

Program Files 下面的目录是只读的，所以运行期数据落在用户目录：

```
%LOCALAPPDATA%\NiceReadingLens\
    config.json      设置
    glossary.json    词表
    mt_cache.json    翻译缓存
    certs\           自签证书
    pages\           每一页的图和识别结果
```

卸载不会删这个目录。想彻底清干净手动删掉即可——翻译缓存和识别过的书页都在里面，重装之后还能接着用。

源码方式运行时这些仍然放在项目里的 `data\`，两种模式互不影响。判断逻辑在 [app/config.py](../app/config.py) 里，靠 `sys.frozen` 区分。

## 几个实现上的选择

**出目录，不出单文件。** onnxruntime 加 opencv 两百多兆，单文件模式每次启动都要先把这些解包到临时目录，开一次十几秒；目录模式秒开。反正有安装包兜着，用户看到的还是一个快捷方式。

**证书不依赖 openssl。** 打包之后用户机器上不一定有 openssl（本机是借 Git for Windows 的），改成用 cryptography 在 Python 里直接签发，SAN 里带 localhost、127.0.0.1 和当前局域网 IP，有效期 820 天。openssl 那条路留着当兜底，正常走不到。

**保留控制台窗口。** 手机端地址和二维码得有地方显示。想要无窗口版本，把 spec 里 `console=True` 改成 `False`，但那就得另外找地方展示地址，不建议。

**图标是构建时画的。** 仓库里不存二进制，`packaging/make_icon.py` 用 PIL 现画一张多尺寸 ico。想换图标改那个脚本。

## 两个编码上的坑

这两个都是这次真踩到的，改文件之前先看一眼，不然构建会以很莫名其妙的方式失败。

**`build.ps1` 里不能出现中文。** Windows PowerShell 5.1 读 `.ps1` 文件时，如果文件没有 UTF-8 BOM，就按系统 ANSI 代码页（中文系统是 GBK）解析。UTF-8 存的中文会被解成乱码，然后直接把脚本语法搞崩，报一堆莫名其妙的 `Missing ')' in function parameter list`。所以这个脚本故意写成纯英文的，别改回中文；真要写中文就得让编辑器存成「UTF-8 带 BOM」。

**`installer.iss` 必须保留 UTF-8 BOM。** Inno Setup 靠开头那三个字节判断文件编码，没有 BOM 就当 ANSI 读，安装界面上的中文会全部变成乱码。这个文件现在是带 BOM 的，用 VS Code 编辑后如果 BOM 没了，装完的向导里就会看到乱码。

顺带一提，`version_info.txt` 里那两处中文写成了 `\uXXXX` 转义，因为 PyInstaller 读版本文件的方式在不同版本间不太一致，转义最省心。

## 改版本号

三个地方要一起改：`packaging/version_info.txt` 里的 `filevers`、`prodvers`、`FileVersion`、`ProductVersion`，`packaging/installer.iss` 里的 `AppVersion`，以及 `app/__init__.py` 里的 `__version__`。

## 中文安装界面

Inno Setup 自带语言里没有中文，需要从官方翻译仓库拿 `ChineseSimplified.isl` 放进 `packaging\`，再把 `installer.iss` 里 `[Languages]` 那两行的注释去掉。

## 实测体积

构建脚本跑通之后量到的：便携目录 254.9 MB，安装包 80.6 MB。大头是 onnxruntime、opencv 和 numpy，省不掉。

没有代码签名，用户第一次运行会被 Windows SmartScreen 拦一下，点「更多信息 → 仍要运行」可以过。要正式发布得买一张代码签名证书，用 signtool 签 exe 和安装包，这一步没做。
